##  About This Collection

This repository contains a collection of **Figma-based UI/UX prototypes and design projects**

Rather than focusing only on visual appearance, these projects explore how users interact with digital interfaces through:

* Information hierarchy
* Navigation
* Layout design
* Visual communication
* Interaction patterns
* User flows
* Usability
* Accessibility considerations
* Consistent interface design
* Prototyping

The collection covers a variety of domains, from **healthcare and education to ticket booking, property marketplaces, portfolios, and mobile interfaces**.

---

##  Design Goals

Across these projects, the main goals were to:

* Apply Human-Computer Interaction principles.
* Design interfaces around user needs and tasks.
* Create clear and intuitive navigation.
* Practice wireframing and prototyping.
* Explore visual hierarchy and composition.
* Develop consistent UI systems.
* Experiment with different digital product types.
* Translate ideas into interactive prototypes.
* Improve practical Figma skills.
* Understand how design decisions affect user experience.

## HCI Concepts Explored

These projects provided practical experience with several Human-Computer Interaction concepts.

### User-Centered Design

Interfaces were designed around the tasks and needs of their intended users rather than focusing purely on visual appearance.

### Information Architecture

Content was organized into logical sections so users can understand where information belongs and how different parts of the interface relate to one another.

### Visual Hierarchy

Different visual properties were used to communicate importance, including:

- Size
- Typography
- Spacing
- Position
- Contrast
- Grouping

### Interaction Design

The prototypes explore how users move through interfaces and complete common tasks such as:

- Registering
- Browsing
- Booking
- Searching
- Managing tasks
- Automating workflows
- Discovering content
- Planning trips
- Viewing information
- Navigating between screens

### Visual Design

The collection also explores:

- Color palettes
- Typography
- Layouts
- Icons
- Cards
- Buttons
- Images
- Branding
- Dark themes
- Luxury & premium aesthetics

## Design Process

A simplified workflow behind these projects can be represented as:

```javascript
        Problem / Idea
              │
              ▼
      Identify the User
              │
              ▼
      Understand the Task
              │
              ▼
     Information Architecture
              │
              ▼
          Wireframe
              │
              ▼
        Visual Design
              │
              ▼
       Interactive Prototype
              │
              ▼
       Review & Refinement
```

The exact process varied depending on the project and its requirements.
